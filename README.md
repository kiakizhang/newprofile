# kiaki. — 个人作品集预览

`index.html` 是最终成品：**单文件、零依赖、可离线**。所有图片和公司 logo 都已内联为 base64，直接双击用浏览器打开即可。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 最终交付文件（约 0.6 MB，自包含） |
| `template.html` | 可编辑源文件，图片位置用 `__IMG_*__` 占位 |
| `build.py` | 把 `template.html` + `assets/` 内联，生成 `index.html` |
| `assets/` | 头像抠图、6 张活动照片（均为 WebP） |
| `assets/logos/` | 四家公司真实 logo PNG（`presence.png` / `mengma.png` / `tencent.png` / `weipai.png`） |

改完 `template.html` 或替换 `assets/` 里的图片后重新生成：

```bash
python3 build.py
```

## 页面结构

1. **首屏 / Hero** — 桌面端左上角由「产品经理 & AI 探索者」替代原 `kiaki.` 字标（页头不再有品牌字标与返回箭头，状态条居中、右侧导航不动），标题保留 eyebrow 排成一行；头像左右两侧对称排布手写问候：左侧「Hello, I'm」、右侧「Kiaki」，两句按渲染宽度等宽（右侧放大 1.5 倍并加字距、基线与左侧对齐），以单笔画矢量路径按真实笔顺逐笔写出（先左后右），笔尖光点跟随当前笔画，写完后停留片刻再淡出重写。插画头像 + 6 张照片组成的 3D 环形传送带：`preserve-3d` 轨道上卡片按索引计算 X / Z 位移与 Y 轴旋转，中间最大、两侧向内倾斜并逐层后退；越靠外越模糊、越暗，左右两端经遮罩渐变融入黑色，整条轨道无限循环漂移
2. **关于 / About** — 居中宣言 + WebGL 水光波纹背景 + 6 张能力卡片（两列三行，描述常显）
3. **职业历程 / Career** — 4 段经历并排（临场感科技 / 梦马智能 / 腾讯 / 微派会玩），顶部为真实公司 logo。桌面端悬浮/聚焦时该列展开：摘要下方出现一条分隔线，线下依次是「技术关键」与全部亮点（不再压住摘要文字）；临场感科技为保密条目，只列出方向关键词，不展开细节。手机端默认收起，只显示 logo、公司名与一行简介，点按展开 / 再次点按收起
4. **荣誉成就 / Honors** — 左侧标题 + 右侧 5 条列表
5. **AI 思考 / Thoughts** — 一张大号引言卡 + 两张半宽卡片
6. **悬浮细节** — 职业卡片、荣誉行、思考卡片悬浮时，两条低亮度流星从左上角同时出发：一条沿上边缘向右、一条沿左边缘向下，在右下角汇合后继续向左、向上绕行
7. **联系 / Contact** — 微信号 / 公众号一键复制、播客与二维码入口

## 预览参数

- `index.html?static=1` — 跳过入场动画、显示全部内容、暂停照片巡展与流星边，适合截图
- `index.html?static=1&y=<px>` — 同时滚动到指定位置

## 交互

- 首屏传送带由 CSS 自定义属性 `--p` 驱动无限循环（88s / 圈），卡片用 `translate3d + rotateY` 排成 360° 环，`blur() / opacity / brightness()` 随角度衰减
- 悬浮任意一张照片：整条轨道暂停、该卡片前移放大、图注淡入、其余照片变暗；键盘 `Tab` 聚焦同样生效
- 鼠标移动时整条轨道带轻微 3D 视差偏移
- 自定义光标（圆点 + 延迟跟随圆环）
- **整页滚动吸附**：滚轮 / 触控板 / `PageUp` `PageDown` `↑` `↓` `空格` `Home` `End` 每次只翻一屏，动画结束后停在下一个整页起点；过高的区块（关于、职业）会各自多出一个「对齐到区块末尾」的页面，末尾页不会超过文档最大滚动距离。触屏设备改为手指跟手拖动、松手吸附一页（无惯性连翻），`prefers-reduced-motion` 与 `?static=1` 下自动关闭
- 导航锚点与翻页共用同一组落点：区块自身的顶部留白够大时对齐真实顶部，不够时下移 88px 让出固定头部；点「历程 / 荣誉 / 思考 / 联系」与滑一页的落位完全一致，触屏下 `scroll-padding-top` 取同一数值
- 关于区能力卡片、职业列支持悬浮 / 键盘聚焦；职业 / 荣誉 / 思考卡片悬浮时出现「双流星绕边」跑马灯描边（两条同时从左上角出发，右下角汇合后继续绕行）
- 职业历程新增「临场感科技 / Presence」条目，内容仅保留 6 个方向：出海 AI、社交产品经理、产品矩阵操盘、上架合规体系、付费与留存设计、AI 驱动提效
- 关于区背景为内联 WebGL 着色器：低分辨率渲染、约 30fps 节流、离开视口/切后台自动暂停，并遵循 `prefers-reduced-motion`
- 首屏分层揭幕、滚动视差、顶部滚动进度条、无限标签跑马灯
- 手写问候为内联单笔画 SVG（Hershey `scriptc` 字形路径），每笔一条 `<path pathLength="1">`，由 JS 逐笔设置 `stroke-dashoffset` 按书写顺序展开；左右两组共用一套「左暖右冷、向内收敛」的渐变，笔尖光点用 `getPointAtLength()` 跟随；桌面端循环播放，`?static=1`、`prefers-reduced-motion` 与无 JS 时静态显示全貌
- 按钮/链接磁吸效果；微信号一键复制并弹出提示
- 响应式：≤1100px 收紧卡片排版；≤900px 全部改为上下堆叠布局；≤700px 能力卡片单列

## 替换素材

- **头像**：把新的透明背景图放到 `assets/portrait.webp`（建议宽 760px 左右、人物居中，底部渐隐可直接烘焙进 alpha），再运行 `python3 build.py`。
- **活动照片**：替换 `assets/` 下对应 WebP，首屏卡片按 16:10 裁切。
- **公司 logo**：`assets/logos/` 内为四家公司的真实 logo，已裁掉白边、统一高度 126px；换成新图后保持文件名不变再运行 `python3 build.py` 即可。卡片里以白色圆角底板呈现，logo 高度随视口在 30–42px 之间缩放。

## 说明

- 正文使用系统字体：微软雅黑 / 黑体 / 苹方（`Microsoft YaHei → Heiti SC → PingFang SC`），全站无斜体，强调处使用加粗。首屏手写问候使用内联的单笔画矢量路径（无字体文件依赖），离线与跨平台显示一致。
- 文案、链接、数据全部来自原项目 `src/data/profile.ts`，未作改写。
- 同目录的 `portfolio-src/` 是原仓库的克隆，仅用于取素材和文案，可随时删除。

## 移动端

- **首屏照片环**：可左右滑动，松手自动吸附到最近一张；点按任意一张把它转到正中并高亮（其余变暗），再点一下取消。首次进入有极慢的自动漂移，一旦手动操作就停下。
- **职业历程**：四张卡片默认收起（logo + 公司名 + 一行小字 + 「展开详情」），点按后高度动画展开全部内容，再点收起；卡片带轻微投影与按压反馈。
- **整页吸附**：手指上下滑动=翻一页，跟手拖动、松手吸附，不受惯性影响；锚点与分页使用同一套目标位置。
- 头像与照片全部改为 WebP 内联，整站从 1.6 MB 降到约 0.6 MB。
